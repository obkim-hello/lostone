## 1. 背景与目标

### 1.1 背景
ADR-004 确定 Persona 蒸馏与对话默认走**本地 LLM**（原文不出设备）。ADR-005 确定端侧栈为 **`flutter_gemma`（LiteRT-LM）**。要让模块 004 的 `LiteRtRuntime` 真正可运行、可测试，必须先有一层**把模型弄到设备上并加载就绪**的能力——即本模块。

**为何提前**：模块 004 的默认（本地）路径在没有"已就绪的本地模型"时无法端到端运行/验收；因此把原路线图 Phase 4 的模型管理**提前到 Phase 3**，与模块 004 配套落地。

### 1.2 目标
- 提供**模型目录**（可下载模型清单 + 元数据：名称/大小/格式/能力/推荐设备档）。
- 提供**下载 → 存储 → 加载就绪**能力：断点续传、进度、校验、失败重试（薄封装 `flutter_gemma` 模型安装 builder API `installModel().fromNetwork().install()`；旧 `ModelFileManager` 为其 legacy facade，封装对 builder API 编程，不自造下载器，ADR-005）。
- 提供**模型切换/删除/查询**：查询已安装模型、当前激活模型、剩余空间；切换激活模型供模块 004 使用。
- 向模块 004 暴露稳定契约：`ModelHandle`（已就绪模型的标识/路径/能力），使 `LiteRtRuntime` 无需关心下载细节。

### 1.3 范围

**包含**：
- 模型目录与元数据（内置清单 + 可扩展）。
- 模型下载/安装（`fromNetwork`）、进度/断点续传、完整性校验、取消。
- 模型存储管理（app documents 目录、占用统计、删除、排除 iCloud/备份的钩子交由模块 008）。
- 模型激活/切换/查询；`ModelHandle` 契约。
- Hugging Face 访问 token 的接收与安全存取（经 Flutter Secure Storage；UI 属 Phase 4）。
- 引擎选择（LiteRtLmEngine 默认 / MediaPipeEngine 备）与设备能力探测（是否支持 Metal GPU、可用内存档）。

**不包含**：
- 实际推理/生成、对话、Persona 蒸馏（属模块 004）。
- 模型管理 UI（下载界面、进度条视觉）（属 Phase 4 / 模块 006 设置页）。
- 云端 API 的 Key 管理（云端属模块 004 Runtime；本模块只管**本地模型**）。
- 训练/微调/LoRA 生产化（v1 仅运行预置量化模型；LoRA 作为后续候选）。
- 加密落盘与备份策略实现（属模块 008；本模块提供排除备份/加密的注入钩子）。

## 2. 用户故事

### 故事 1：新用户 - 一键获取一个能用的本地模型
**作为**：首次使用、想完全离线生成人格的用户
**我想要**：从推荐列表里选一个适合我手机的模型并下载
**以便于**：无需懂技术就能让本地 LLM 跑起来

**验收标准**：
- [ ] 给定模型目录，当查看，则每个模型显示大小/推荐设备档/能力，并按设备内存给出推荐项。
- [ ] 给定选择某模型，当下载，则显示进度、支持断点续传，完成后校验通过并标记"已就绪"。
- [ ] 给定下载完成，当模块 004 请求推理，则能拿到 `ModelHandle` 直接加载，无需再次下载。

**优先级**：高

---

### 故事 2：隐私/流量敏感用户 - 可控、可离线
**作为**：在意流量与隐私的用户
**我想要**：明确知道模型多大、下到哪、可删除，且下载只发生在我发起时
**以便于**：掌控存储与网络，避免意外流量

**验收标准**：
- [ ] 给定任一模型，当查看，则显示占用空间与本地路径（app 私有目录）。
- [ ] 给定已安装模型，当删除，则释放空间并从已安装列表移除；若为激活模型则回退到"无激活模型"。
- [ ] 给定未主动下载，当使用 app，则不发生任何模型网络请求。

**优先级**：高

---

### 故事 3：低端设备用户 - 不下超出能力的模型
**作为**：老旧/低内存设备用户
**我想要**：系统阻止或警告我下载跑不动的大模型
**以便于**：不浪费空间、不遇到加载崩溃

**验收标准**：
- [ ] 给定设备内存/GPU 能力，当浏览目录，则超档模型被标注"可能无法运行"并需二次确认。
- [ ] 给定在 iOS 模拟器（仅 CPU、Metal 256MB），当尝试加载大模型，则给出明确不支持提示，仅允许 SmolLM 135M 类冒烟模型（ADR-005）。

**优先级**：中

---

### 故事 4：开发者（模块 004）- 稳定契约、无需关心下载
**作为**：模块 004 的实现者
**我想要**：一个"给我当前激活的、已就绪模型"的稳定接口
**以便于**：`LiteRtRuntime` 只管推理，不管下载/存储/版本

**验收标准**：
- [ ] 给定已安装并激活的模型，当模块 004 调用 `getActiveModelHandle()`，则返回含路径/格式/能力的 `ModelHandle`。
- [ ] 给定无激活/未就绪模型，当调用，则返回明确的"不可用"状态（供模块 004 回退统计兜底，对齐 ADR-004）。

**优先级**：高

## 3. 功能清单

### 3.1 核心功能

#### 功能 1：模型目录（ModelCatalog）
**描述**：内置可下载模型清单 + 元数据；按设备能力推荐。
**业务规则**：每条含 `id/displayName/format(.litertlm/.task)/sizeBytes/capabilities/minTierRecommendation/sourceUrl`；目录可扩展但来源受信任。
**优先级**：P0

#### 功能 2：下载 / 安装（ModelInstaller）
**描述**：薄封装 `flutter_gemma` 模型安装 builder API `installModel().fromNetwork(url).withProgress(...).install()`（旧 `ModelFileManager` 为 legacy facade）；进度、断点续传、校验、取消、失败重试。
**业务规则**：只在用户发起时下载；下载中可取消并清理半成品；完成后做完整性校验（大小/可加载）方标"已就绪"；HF token 按需注入。
**优先级**：P0

#### 功能 3：存储管理（ModelStore）
**描述**：查询已安装模型、占用空间、删除；模型落于 app documents 目录（ADR-005）。
**业务规则**：删除释放空间并更新状态；提供"排除备份/加密"注入钩子（实现属模块 008）；不把大模型放 assets（须落盘内存映射）。
**优先级**：P0

#### 功能 4：激活 / 切换 / 查询（ActiveModel + ModelHandle）
**描述**：设置当前激活模型；向模块 004 暴露 `getActiveModelHandle()`；查询安装/就绪状态。
**业务规则**：同一时刻单一激活模型（v1）；切换即时生效；无就绪模型返回"不可用"。
**优先级**：P0

#### 功能 5：设备能力探测 + 引擎选择
**描述**：探测 GPU(Metal)/内存档，选择引擎（LiteRtLmEngine 默认 / MediaPipeEngine 备）与后端（GPU/CPU）。
**业务规则**：模拟器/无 GPU → CPU + 仅冒烟模型；据能力做下载前告警（故事 3）。
**优先级**：P1

### 3.2 辅助功能
#### 功能 A：HF token 安全存取（Flutter Secure Storage）——供受限模型下载。P1
#### 功能 B：模型完整性/版本校验与损坏恢复（重下）。P1

## 4. 非功能性需求

### 4.1 性能
- 下载：支持断点续传，弱网可恢复；进度回调延迟 < 500ms。
- 加载就绪：模型加载时间对齐 CLAUDE.md「本地模型加载 < 3s」（受模型大小/设备影响，ERD 分档）。
- 不阻塞 UI：下载/加载在后台，进度可观测。

### 4.2 安全与隐私
- 只下载用户发起的模型；不发送用户聊天数据（本模块不接触原文）。
- HF token / 云端凭据经 Flutter Secure Storage；日志不含完整 token。
- 模型文件位于 app 私有目录；加密/排除备份钩子交模块 008。

### 4.3 可用性
- 无网络/下载失败/空间不足/损坏文件/超档设备等均有明确状态与恢复路径，不崩溃。

### 4.4 兼容性
- iOS 16.0+（ADR-005）；Runner.entitlements（扩展虚拟寻址/放宽内存 + disable-library-validation）、Info.plist `UIFileSharingEnabled`、Podfile 静态链接。
- macOS Apple Silicon 同栈支持；模拟器仅 CPU + 冒烟模型。

## 5. 数据要求

### 5.1 输入
| 数据项 | 类型 | 必填 | 来源 | 验证 |
|--------|------|------|------|------|
| modelId | `String` | 是 | 用户/目录 | 存在于目录 |
| hfToken | `String?` | 否 | 用户设置 | 受限模型时需要；Secure Storage |
| runtimeConfig | 引擎/后端偏好 | 否 | 设置/探测 | 依设备能力 |

### 5.2 输出
| 数据项 | 类型 | 说明 |
|--------|------|------|
| ModelHandle | 对象 | `{id, filePath, format, capabilities, backend}`，供模块 004 |
| InstallProgress | 流 | 进度/完成/错误事件 |
| InstalledModel[] | 列表 | 已安装模型 + 大小 + 就绪状态 |

### 5.3 存储
- 模型文件：app documents 目录（`flutter_gemma` 默认位置，ADR-005）。
- token/凭据：Flutter Secure Storage。
- 目录/激活状态元数据：轻量本地存储（Hive/JSON，模块内自管）。

## 8. 验收标准

### 8.1 功能
- [ ] 目录展示 + 按设备推荐；下载支持进度/断点续传/取消/校验。
- [ ] 已安装列表/占用/删除/激活切换正确；`getActiveModelHandle()` 契约稳定。
- [ ] 无就绪模型时返回明确"不可用"（供模块 004 兜底）。
- [ ] 未主动下载则无任何模型网络请求。

### 8.2 性能
- [ ] 模型加载 < 3s（分档，ERD）；进度回调 < 500ms。

### 8.3 安全
- [ ] token 经 Secure Storage、日志脱敏；模型落 app 私有目录。

### 8.4 质量
- [ ] 单测覆盖率 > 80%（目录/状态机/存储/激活/能力探测，用 mock 下载与文件系统）。
- [ ] `flutter analyze` 0 警告。
- [ ] **真机冒烟**：iPhone(iOS16+) 下载 Gemma 3 1B 并加载就绪（分阶段，需设备）。
