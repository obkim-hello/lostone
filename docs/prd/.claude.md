---

## 📝 编写流程

1. **复制模板**：`cp PRD-TEMPLATE.md PRD-{模块名}-{编号}-{日期}.md`
2. **填写内容**：按模板章节填写产品需求
3. **提交评审**：提交 PR 进行团队评审
4. **批准归档**：批准后将文件名中的日期改为批准日期
5. **关联文档**：创建对应的 ERD 和 Spec（使用相同编号和日期）
6. **开始开发**：三文档齐全且批准后开始开发
