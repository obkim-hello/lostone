## 📝 编写流程

1. **PRD 评审通过**：确认 PRD 已批准
2. **复制模板**：`cp ERD-TEMPLATE.md ERD-{编号}-{模块名}.md`
3. **填写技术方案**：数据结构、接口设计、实现细节
4. **评审文档**：技术评审（架构师、资深工程师）
5. **关联 Spec**：创建技术规格文档
6. **开始开发**：ERD 评审通过后进入开发
