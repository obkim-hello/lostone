## 📋 文档类型说明

### PRD（Product Requirement Document）
- **用途**：产品需求文档，从产品视角描述功能
- **粒度**：模块级别
- **命名**：`PRD-{编号}-{模块名}.md`
- **模板**：`PRD-TEMPLATE.md`

### ERD（Engineering Requirement Document）
- **用途**：工程需求文档，从技术视角描述实现
- **粒度**：模块级别
- **命名**：`ERD-{编号}-{模块名}.md`
- **模板**：`ERD-TEMPLATE.md`

### Spec（Technical Specification）
- **用途**：技术规格，定义模块接口和测试用例
- **粒度**：模块接口级别
- **命名**：`SPEC-{编号}-{模块名}.md`
- **模板**：`SPEC-TEMPLATE.md`

## 📝 文档编写流程

1. **确定文档类型**：PRD、ERD 还是 Spec
2. **复制对应模板**：从 `*-TEMPLATE.md` 复制
3. **填写内容**：按模板章节填写
4. **提交评审**：提交 PR 进行评审
5. **评审通过**：合并到主分支

## ✅ 文档质量检查

每个文档提交前必须检查：

- [ ] 使用了正确的模板
- [ ] 所有必填章节已完成
- [ ] 文档命名符合规范

- [ ] 已关联相关文档（PRD ↔ ERD ↔ Spec）
